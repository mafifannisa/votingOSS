PRODUCT REQUIREMENTS DOCUMENT (PRD)
APLIKASI E-VOTING PEMILIHAN KETUA OSIS
Tema UI: Paper Card

============================================================
1. RINGKASAN PRODUK
============================================================

Aplikasi ini merupakan sistem E-Voting Pemilihan Ketua OSIS berbasis web
yang memungkinkan siswa melakukan pemilihan secara digital menggunakan
NISN sebagai identitas pemilih.

Sistem terdiri dari dua area utama:

A. HALAMAN PEMILIH
1. Memasukkan NISN.
2. Sistem memvalidasi NISN berdasarkan data siswa yang telah diinput admin.
3. Jika belum memilih, pemilih masuk ke halaman pemilihan.
4. Pemilih melihat pasangan calon beserta foto, nama, jurusan, visi, dan misi.
5. Pemilih memilih satu pasangan calon.
6. Pemilih melakukan konfirmasi.
7. Suara otomatis tersimpan.
8. Status pemilih berubah menjadi sudah memilih.
9. Pemilih otomatis kembali ke halaman login.

NISN yang sudah digunakan untuk memilih tidak dapat digunakan kembali.

B. HALAMAN ADMIN
Admin dapat:
- Login.
- Mengelola data pasangan calon.
- Mengelola data siswa/pemilih.
- Import data siswa dari Excel.
- Melihat statistik pemilihan.
- Mengakses halaman hasil pemilihan menggunakan kode akses.
- Melihat hasil Paslon 1 dan Paslon 2 setelah animasi penghitungan 60 detik.

============================================================
2. TUJUAN SISTEM
============================================================

Sistem bertujuan membuat proses pemilihan Ketua OSIS yang:
- Cepat.
- Mudah digunakan.
- Mengurangi penggunaan kertas.
- Mencegah pemilih memilih lebih dari satu kali.

Jika sqlite3.connect() memang diwajibkan oleh tugas, penggunaannya

20. PARAMETERIZED QUERIES
============================================================

WAJIB menggunakan parameterized query.

Jangan:
$sql = "SELECT * FROM voters WHERE nisn='$nisn'";

Gunakan PDO prepared statement:

$stmt = $pdo->prepare(
    "SELECT * FROM voters WHERE nisn_hash = ?"
);

$stmt->execute([$nisnHash]);

Tujuan:
- Mencegah SQL Injection
- Memisahkan query dan data input

============================================================
21. ENKRIPSI DAN HASHING
============================================================

Password admin:
password_hash()
password_verify()

Kode akses hasil:
password_hash()
password_verify()

NISN:
Gunakan HMAC-SHA256 untuk kebutuhan pencarian.

NISN asli
   |
   v
HMAC-SHA256
   |
   v
nisn_hash

Untuk data yang memang harus dapat didekripsi, gunakan encryption
modern seperti AES-256-GCM dan simpan encryption key di environment
secret, bukan di source code.

============================================================
22. SESSION SECURITY
============================================================

Setelah login:
session_regenerate_id(true);

Session sebaiknya:
- HTTPOnly
- Secure jika HTTPS digunakan
- SameSite sesuai kebutuhan
- Memiliki timeout
- Dihapus setelah voting

Setelah voting:
session_destroy();

Kemudian redirect ke halaman login.
